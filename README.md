# ppxsatpro-theme

CSS personalizado da loja PPXSATPRO (Nuvemshop, tema Ipanema). Mantido pela Zagaia.

A loja carrega `ppx.css` via jsDelivr, travado num commit:

```css
@import url('https://cdn.jsdelivr.net/gh/gbrielvascn/ppxsatpro-theme@<commit>/ppx.css');
```

Para publicar uma mudança: commit aqui e atualize o hash no campo "CSS personalizado" do editor da Nuvemshop.
